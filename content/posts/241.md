<p><strong>实际使用:</strong></p>
<p>CurrentValue.[商品编码] = &quot;X9Y4P8A9&quot; ，商品编码是字段名，[]里字段名不需要加引号，不需要点亮python模式，而且一定要用双引号，即便里面是字符串变量外面也要有双引号</p>
<p>多维表日期类型字段目前发现可用的筛选条件写法： 正常的日期格式不能写入</p>
<p>CurrentValue.[销售日期] &gt;= TODAY()-1</p>
<p>CurrentValue.[销售日期] &gt;= DATE(2025,2,26)</p>
<p>CurrentValue.[销售日期] = NOW() 不太好用，感觉在实际筛选中用处不大</p>
<p>猜测可能能用的：</p>
<ul>
<li>
<p>NOW()：返回当前的日期和时间，而 TODAY () 只返回当前日期，不包含时间信息。在需要获取精确到秒甚至毫秒级别的当前时间时，NOW () 就很有用。比如在记录操作日志，需要精确到具体时间点时，可以使用 NOW ()。</p>
</li>
<li>
<p>DATE (年，月，日)：用于创建一个指定年、月、日的日期。与 TODAY () 不同，它不是获取当前日期，而是根据传入的参数生成特定日期。例如，DATE (2025,5,1) 会返回 2025 年 5 月 1 日这个日期。在设置一些固定的纪念日、截止日期等场景中会用到。</p>
</li>
<li>
<p>ADDDAYS (数字，日期)：用于为指定日期加 / 减一定天数。它可以基于某个给定日期进行天数的增减操作，而 TODAY () 是获取当前日期。比如 ADDDAYS (7,TODAY ()) 可以得到从今天开始 7 天后的日期，常用于计算未来或过去的某个日期。</p>
</li>
<li>
<p>ADDMONTHS (数字，日期)：为指定日期加 / 减一定月数。与 TODAY () 的功能不同在于，它主要用于月份的增减计算。例如，ADDMONTHS (3,TODAY ()) 可以计算出从当前日期开始 3 个月后的日期，适用于计算月票到期日、季度结算日等场景。</p>
</li>
<li>
<p>ADDYEARS (数字，日期)：为指定日期加 / 减一定年数。和 TODAY () 相比，更侧重于年份的变化。比如 ADDYEARS (1,TODAY ()) 可以得到明年的今天的日期，在计算合同续签日期、长期计划的时间节点等方面很实用。</p>
</li>
</ul>
