<h3>效果如下：</h3>
<p><img src="https://tuchuang.shifengzhi.top/picture/beautifulShadow.png" alt="" /></p>
<h3>代码实现</h3>
<pre><code>&lt;!DOCTYPE html&gt;
&lt;html lang=&quot;en&quot;&gt;
&lt;head&gt;
  &lt;meta charset=&quot;UTF-8&quot;&gt;
  &lt;meta name=&quot;viewport&quot; content=&quot;width=device-width, initial-scale=1.0&quot;&gt;
  &lt;title&gt;Document&lt;/title&gt;
  &lt;style&gt;
    * {
      margin: 0;
      padding: 0;
      box-sizing: border-box;
    }
    body {
      height: 100vh;
      background: linear-gradient(45deg, #bfbfbf, #e6e6e6);
      display: flex;
      justify-content: center;
      align-items: center; /* 垂直居中 */
    }
    h1 {
      font-size: 20vmin;
      font-family: &#039;Courier New&#039;, Courier, monospace;
      line-height: 1;
      margin: 0;
      letter-spacing: 5px;
      color: #e6e6e6;
      text-align: center;
      text-shadow: 1px -1px #fff, /* 水平偏移1px，垂直偏移1px，白色 */
                    -1px 1px #999, /* 水平偏移-1px，垂直偏移1px，灰色 */
                    -10px 10px 5px #80808080; /* 水平偏移-10px，垂直偏移10px，模糊半径5px，灰色 */
    }
  &lt;/style&gt;
&lt;/head&gt;
&lt;body&gt;
  &lt;h1&gt;Beautiful Shadow Text Effect&lt;/h1&gt;
&lt;/body&gt;
&lt;/html&gt;</code></pre>
