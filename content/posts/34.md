<p>程序中可以改变的量</p>
<p>变量的三大要素（三大组成部分）</p>
<p>数据类型  变量名  变量值</p>
<p>1.声明变量：数据类型 变量名；int a;</p>

<p><strong>变量名的建议规范</strong></p>
<p>变量名遵循驼峰命名法，即首字母小写，其后每个单词首字母大写，strScore</p>
<p>不建议使用汉字，尽量使用英文单词或拼音，要见名知意</p>
<p>不建议使用单个字母命名，约定俗成的除外</p>
<p>不建议以下划线开头，不建议使用$</p>
<p>命名法：</p>
<p>驼峰命名法：classId</p>
<p>帕斯卡命名法：ClassId</p>
<p>蛇底式命名法：class_id</p>
<p>尖叫蛇底式命名法：CLASS_ID</p>
<p><strong>标识符强制规范</strong></p>
<p>1.可由字母，数字，下划线，$组成</p>
<p>2.不能以数字开头</p>
<p>3.字母区分大小写</p>
<p>4.不能使用关键字，字面量，保留字</p>
<p>5.在同一作用域下名称不能重名</p>
<p>关键字：是Java定义好的具有特定含义的单词，public ,class ,int...</p>
<p>字面量：是Java定义好的一些值：true，false，null</p>
<p>保留字：是Java的前身Oak和前代语言C、C++的关键字，但是在Java中没有使用却保留下来的，const，goto</p>

<h2>运算符</h2>
<p>算术运算符，赋值运算符，关系运算符，逻辑运算符，条件运算符</p>
<p>【算术运算符】</p>
<p>​   +、-、*、/、%、++、--</p>
<p>​   1.两个整数相除的结果是整数（即整除），若想得到小数结果，需要将其中一个强制类型转换成浮点数</p>
<p>​   2.利用整除可以去掉最后一位：整数/10</p>
<p>​   3.浮点类型的计算不一定精准(加减乘除%)</p>
<p>​   4.取余数</p>
<p>​       1）负数取余数，以第一个数的正负为准，若第一个数是正数，则结果为正，若第一个数是负数，则结果为负</p>
<p>​       2）判断奇偶，数%2，若结果是0则是偶数，若结果非0则是奇数</p>
<p>​       3）获取整数的最后一位：整数%10</p>
<p>​       4）判断整数：数%1，若结果是0则是整数，若结果非0则是奇数</p>
<p>​   5.两种类型进行计算的结果</p>
<p>​       1）都是整数类型，若由long类型参与，则结果为long类型，否则为int类型</p>
<p>​       2）若有浮点类型参与，如果有double类型参与，则结果为double类型，否则为float类型</p>
<p>​   6.除了boolean之外的七种类型，都可以进行算术运算</p>
<p>​   7.++、--</p>
<p>​   ++：自加1    --自减1</p>
<p>​   a++：先用后加</p>
<p>​   ++a：先加后用</p>

<p>【逻辑运算符】</p>
<p>​   与   或   非</p>
<p>​   与：并且，如果两个条件同时为true，则结果是true</p>
<p>​   &amp;&amp;：短路与，如果第一个条件为false，则不会判断第二个条件</p>
<p>​   &amp;：非短路与，即使第一个条件为false，也会判断第二个条件</p>
<p>​   或：或者，如果有一个条件为true，则结果为true</p>
<p>​   ||：短路或，如果第一个条件为true，则不会判断第二个条件</p>
<p>​   |：非短路或，即使第一个条件为true，也会判断第二个条件</p>
<p>​   非：取反    ！</p>
<p>【条件运算符】</p>
<p>​   ? :</p>
<p>​   布尔类型表达式 ? 结果为true则执行此部分 : 否则执行此部分</p>

        int b = 10;

        int max;
        // 方式一

<h2>面向对象</h2>
<p>面向过程：是具体化的，流程化的，解决一个问题，你需要一步一步的分析，一步一步的实现，注重的是具体实现                  过程，每个步骤亲历亲为</p>
<p>​                   例：吃饺子=》和面，和馅，包，蒸，....自己弄</p>
<p>面向对象：是模型化的，注重的是对象与对象之间的协作，不必去一步一步的实现</p>
<p>​                   例：吃饺子=》点外面，商家做，骑手送，自己吃</p>
<p>​   优点：易维护，易复用，易扩展，由于面向对象有封装，继承，多态的特性，可以设计出低耦合的系统，使系                统更加灵活，更加易于维护</p>
<p>类：是一种抽象的表示，可以把具有相同特征的事物归为一类，例：人类，车类，鸟类</p>
<p>对象：类别中具体的一个事物</p>
<p>对象的成员：</p>
<p>​   1.属性：指对象的特征</p>
<p>​   2.方法：指对象的动作（行为）</p>

<p>访问修饰符  class 类名{</p>
<p>}</p>

<p>}</p>
<p><strong>方法参数</strong>：方法中需要数据，但是它本身没有，需要从外部传入时，就要定义参数</p>
<p>形参：形式参数，在方法定义时写的参数</p>
<p>实参：实际参数，在方法调用时传入的参数</p>
<p><strong>返回值</strong>：外部需要方法内部数据</p>
<p>​   1.在定义方法时，需要指定返回值类型</p>
<p>​   2.在方法体中，使用return关键字，返回一个具体的值</p>
<p><strong>方法重载</strong>：方法名相同，参数列表不同（参数的个数不同，参数类型不同）</p>

<h2>正则表达式</h2>
<p>Java是从Java 1.4开始支持的正则表达式</p>
<p>正则表达式，简写为regex，regxp，regexp</p>
<p>是用于匹配、查找、替换文本等操作的表达式</p>
<p>正则表达式中包含普通字符和元字符</p>
<p>元字符就是一类特殊的字符，有具体的含义</p>
<p>^、$：开始和结束</p>
<p>[abc] ：匹配abc中任意字符</p>
<p>[^abc] ：除了abc的任意字符</p>
<p>[a-z] ：a到z之间的字符</p>
<p>[a-zA-Z0-9] ：a到z，A到Z，0到9之间的任意字符</p>
<p>\d ：数字字符，等效于[0-9]</p>
<p>\w ：单词字符，等效于[a-zA-Z0-9_]</p>
<p>\s ：空白字符，如空格，制表符，换行，回车</p>
<p>\D ：非数字字符</p>
<p>\W ：非单词字符</p>
<p>\S ：非空白字符</p>
<p>? ：0到1个</p>
<p>*：0到多个</p>
<p>+：1到多个</p>
<p><strong>.</strong> ：任意字符</p>
<p>| ：或者</p>
<p>\ ：转义</p>
<p>X{n}：n个X</p>
<p>X{n,}：n到多个X</p>
<p>X{n,m}：n到m个X</p>
<p>^：非</p>
<p>()：分组</p>

<p>1.分时调度：所有线程轮流使用CPU的使用权，平均分配每个线程占用CPU事件</p>

<p>1.使用同步代码块解决</p>
<p>格式synchronized(锁对象){</p>

<pre><code class="language-Java">package com.zretc.javase.d0324;

/*
 * 卖票案例出现了线程安全问题，卖出了不存在的票和重复的票
 * 
 * 解决线程安全问题的第一种方案：使用同步代码块
 * 格式：
 * synchronized(锁对象){
 *  可能会出现线程安全问题的代码（访问了共享数据的代码）
 * }
 * 注意：1.通过代码块中的锁对象，可以使用任意的对象
 *   2.但是必须保证多个线程使用的锁对象是同一个
 *   3.锁对象作用：把同步代码块锁住，只让一个线程在同步代码块中执行
 * 
 */
public class TicketThread implements Runnable {

    private int ticket = 100;

    // 创建一个锁对象
    Object obj = new Object();

    // 设置线程任务：卖票
    @Override
    public void run() {
        // 使用死循环，让卖票操作重复执行
        while (true) {
            synchronized (obj) {
                // 先判断票是否存在
                if (ticket &gt; 0) {
                    // 票存在，卖票，ticket--
                    System.out.println(Thread.currentThread().getName() + &quot;--&gt;正在卖第&quot; + ticket + &quot;张票&quot;);
                    ticket--;
                }
            }
        }
    }

}</code></pre>

<p>1.新建状态：线程被建立</p>
<p>2.就绪状态：将新建的线程，加入到执行队列中</p>
<p>3.运行状态：线程被执行</p>
<p>4.阻塞状态：执行过程中发生了等待状态，导致线程暂停</p>
<p>5.消亡状态：线程结束</p>
<p>同步：顺序执行（ABCD接力赛）</p>
<p>异步：同时执行（ABCD比赛）</p>

<pre><code class="language-Java">package com.zretc.javase.d0325.p3;

import java.text.SimpleDateFormat;
import java.time.LocalDate;
import java.time.LocalDateTime;
import java.time.LocalTime;
import java.time.format.DateTimeFormatter;
import java.util.Calendar;

public class Demo {

    public static void main(String[] args) {
        Calendar cal = Calendar.getInstance();
        System.out.println(cal);
        // 获取Date对象
        System.out.println(cal.getTime());
        SimpleDateFormat f = new SimpleDateFormat(&quot;yyyy-MM-dd HH:mm:ss&quot;);
        // 转成格式化字符串
        System.out.println(f.format(cal.getTime()));
        System.out.println(cal.get(Calendar.MONTH) + 1 + &quot;月&quot;);// 0-11
        System.out.println(cal.get(Calendar.DAY_OF_WEEK) - 1);// 1-7 周日是第一天

        // jdk 8之后新增时间类
        LocalDate ld = LocalDate.now();// 获取当前系统时间
        System.out.println(ld);// 2022-03-25

        LocalDate ld2 = LocalDate.of(2023, 3, 1);// 指定时间
        System.out.println(ld2);
        // 通过控制当前赋值的正负数，完成是加还是减
        ld2 = ld2.plusYears(-3);
        System.out.println(ld2);
        // 月份
        ld2 = ld2.plusMonths(-13);
        System.out.println(ld2);
        // 日期
        ld2 = ld2.plusDays(1);
        System.out.println(ld2);
        // 周,1代表7天
        ld2 = ld2.plusWeeks(2);
        System.out.println(ld2);

        System.out.println(&quot;=========================&quot;);
        // 格式化
        DateTimeFormatter dtf = DateTimeFormatter.ISO_LOCAL_DATE;// 获取系统设置好的时间格式
        System.out.println(dtf);
        // 转成格式化字符串
        System.out.println(dtf.format(ld));// 2022-03-25
        // 设置时间格式
        DateTimeFormatter dtf2 = DateTimeFormatter.ofPattern(&quot;yyyy/MM/dd&quot;);
        // 转成格式化字符串
        System.out.println(dtf2.format(ld));// 2022/03/25

        System.out.println(&quot;***************************&quot;);
        // 时分秒毫秒
        LocalTime lt = LocalTime.now();
        System.out.println(lt);
        // 格式化字符串
        DateTimeFormatter d1 = DateTimeFormatter.ofPattern(&quot;HH:mm:ss:SSS&quot;);// HH:24进制 hh：12进制
        System.out.println(d1.format(lt));

        System.out.println(&quot;############################&quot;);
        // 年月日-十分秒毫秒
        LocalDateTime lt2 = LocalDateTime.now();
        System.out.println(lt2);
        // 格式化字符串
        DateTimeFormatter d2 = DateTimeFormatter.ofPattern(&quot;dd/MM/yyyy HH:mm:ss&quot;);
        String str = d2.format(lt2);
        System.out.println(str);

    }

}
