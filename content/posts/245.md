<h2>问题清单（复制即用）</h2>
<h3>1 域名打不开</h3>
<p><strong>原因</strong>：阿里云安全组未放行 80 端口<br />
<strong>解决</strong>：</p>
<ol>
<li>登录阿里云控制台 → 安全组 → 入方向</li>
<li>添加规则：<code>TCP 80 0.0.0.0/0 允许</code></li>
</ol>
<hr />
<h3>2 访问域名后自动跳转到 <code>:8080</code></h3>
<p><strong>原因</strong>：WordPress 地址仍带端口<br />
<strong>解决</strong>：</p>
<ol>
<li>
<p>进入 MySQL 容器终端  </p>
<pre><code class="language-bash">
docker exec -it mysql-word_cjfsec mysql -u root -p</code></pre>
</li>
<li>
<p>执行SQL</p>
<pre><code>UPDATE wp_options SET option_value=&#039;http://boki.shifengzhi.top&#039;
WHERE option_name IN (&#039;siteurl&#039;,&#039;home&#039;);</code></pre>
</li>
<li>
<p>后台输入账号密码无反应
原因：登录表单跨域（siteurl 是 IP，浏览器地址是域名）
解决：同问题 2，确保两个地址都是域名即可</p>
</li>
<li>
<p>点击“首页”菜单跳转到 www.shifengzhi.top</p>
<ol>
<li>原因：菜单项写死旧 URL</li>
<li>解决：
3.后台 → 外观 → 菜单
4.找到“首页”项，展开 ▼
5.把 URL 改为 <a href="http://boki.shifengzhi.top">http://boki.shifengzhi.top</a>
6.保存菜单</li>
</ol>
</li>
<li>
<p>IP:8080 返回 404
原因：已关闭 8080 外网端口
解决：无需处理，这是预期安全行为</p>
</li>
</ol>
