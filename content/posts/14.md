<h1>使用WordPress搭建个人博客——完整版(包括图床搭建与Typora设置)</h1>
<h2>一、搭建个人博客</h2>
<ol>
<li>
<p>下载WordPress</p>
<p>地址：WordPress官网：<a href="https://cn.wordpress.org/">https://cn.wordpress.org/</a></p>
</li>
<li>
<p>购买域名</p>
<p>因为域名需要等待时间实名认证，所以这里我们先买域名，顺便等待WordPress下载。</p>
<ul>
<li>
<p>百度搜索域名购买，按个人喜好选择即可，如：阿里云，腾讯云，华为云，百度云等等，这里以<strong>阿里云</strong>为例，地址：<a href="https://domain.aliyun.com/">https://domain.aliyun.com/</a></p>
</li>
<li>
<p>进入网站之后先进行注册和登录，然后随意填写一个自己喜欢的域名名字并选择一个后缀，不同后缀价格不同，如下图：</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328145545620.png" alt="image-20240328145545620" /></p>
</li>
<li>
<p>购买完成并实名之后进入域名控制台，点击网站右上角的<strong>控制台</strong>，进入后点击最左上角的三个横杠图标，点击<strong>域名</strong>选项，如下：</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328150219658.png" alt="image-20240328150219658" /></p>
</li>
<li>
<p>进来后点击<strong>域名列表</strong>，就可以看到自己的域名以及状态了，如图：</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328150423552.png" alt="image-20240328150423552" /></p>
</li>
</ul>
</li>
<li>
<p>购买服务器</p>
<ul>
<li>
<p>依然按自己喜欢随意购买即可，这里以<strong>彩虹云主机</strong>为例，主要是这个更便宜一些，彩虹云主机官网：<a href="https://www.cccyun.net/">https://www.cccyun.net/</a></p>
</li>
<li>
<p>进入网站之后先进行注册和登录，然后点击<strong>订购产品</strong>，如下图：</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328141148114.png" alt="image-20240328141148114" /></p>
</li>
<li>
<p>选择香港主机，具体看个人喜好，对于博客来说基础版就够用了，如下图：（购买时间按个人需要填就可以，购买前记得先充值 余额）</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328141552704.png" alt="image-20240328141552704" /></p>
</li>
<li>
<p>购买好后在<strong>我的产品与服务</strong>界面点击面板用户名进入<strong>产品管理——我的产品与服务详情</strong>页面，点击<strong>前往控制面板</strong>再点击<strong>一键登录控制面板</strong>，(正常都可以进去，如果进不去先点击旁边的<strong>重置产品密码</strong>再一键登录)，进入后找到下图所示位置，将第一步下载好的WordPress中的文件(可以本地解压后把里面上传也可以上传后解压再移动删除)全部放到<strong>wwwroot</strong>文件夹中，如下图：</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328144203793.png" alt="image-20240328144203793" /></p>
</li>
</ul>
</li>
<li>
<p>绑定域名和服务器</p>
<ul>
<li>
<p>在第2步最后的域名界面点击右侧的解析</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328150838528.png" alt="image-20240328150838528" /></p>
</li>
<li>
<p>进入后点击<strong>添加记录</strong>，填写如下图所示，其中的记录值要填写的内容在服务器域名绑定页面里，见下面图：</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328151544335.png" alt="image-20240328151544335" /></p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328152547776.png" alt="image-20240328152547776" /></p>
</li>
<li>
<p>在上图服务器相同页面下面位置的域名填写框中填入 <strong>www.你购买的域名</strong> (就像www.baidu.com)这样</p>
</li>
<li>
<p>填写好后就可以在浏览器中输入你的域名进行访问了，出现如下界面就代表你已经取得了阶段性的成功！</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328153029815.png" alt="image-20240328153029815" /></p>
</li>
<li>
<p>胜利在望，让我们继续吧！</p>
</li>
</ul>
</li>
<li>
<p>初始化WordPress</p>
<ul>
<li>
<p>点击上面图所示页面的<strong>现在就开始！</strong>按钮，进入需要填写信息的页面，这里所需要填写的信息的都在我们的服务器<strong>控制面板首页</strong>右侧的<strong>账户信息</strong>当中，将对应的信息填入即可</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328153749275.png" alt="image-20240328153749275" /></p>
</li>
<li>
<p>填写完成后会看到下图所示页面，点击<strong>运行安装程序</strong></p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328153955067.png" alt="image-20240328153955067" /></p>
</li>
<li>
<p>进入一个填写信息的页面，站点标题就是网站的名字，日后可以进行更改，用户名和密码用于登录，都填好后点击 <strong>安装 WprdPress</strong> 按钮，等待一会输入你的用户名和密码进行登录就进入到WordPress<strong>仪表盘</strong>页面，在这里你可以控制、更改、编辑你的博客网站，诸如写文章，更改外观、主题样式、编辑博客页面内容，安装插件等。</p>
</li>
<li>
<p>此时你在浏览器中输入你的域名就可以看到你的博客网站页面了。好耶！ヽ(✿ﾟ▽ﾟ)ノ 成功了！这个页面是WordPress为你自动生成的默认示范页面，你可以在外观选项中自己更换外观主题和编辑页面内容，如下图：</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328155055902.png" alt="image-20240328155055902" /></p>
</li>
</ul>
</li>
</ol>
<hr />
<h2>二、搭建自己的图床</h2>
<p>为不知道图床的同志简单说一下什么是图床，图床就是一个存图片的地方，可以把你的图片放在网上，在任何地方都可以直接访问到你的图片</p>
<ol>
<li>
<p>PicGo</p>
<p>搭建图床之前我们先来下载一个软件：PicGo，这是帮我们把图片上传到图床的软件，PicGo下载地址：<a href="https://github.com/Molunerfinn/PicGo/releases">https://github.com/Molunerfinn/PicGo/releases</a></p>
</li>
<li>
<p>搭建图床</p>
<p>安装好软件后我们打开<strong>七牛云</strong>的官网，与上面同理，用别的也可以，这里以<strong>七牛云</strong>举例，七牛云官网：<a href="https://www.qiniu.com/">https://www.qiniu.com/</a></p>
<ul>
<li>
<p>进入网站后先进行注册并登录，登录好后点击右上角的<strong>控制台</strong>，进入页面后点击最左上角的三个横杠的菜单图标，点击<strong>对象存储 Kodo</strong>，进来后点击<strong>空间管理</strong>，点击<strong>新建空间</strong>，填写内容及选项见下图：</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328161247591.png" alt="image-20240328161247591" /></p>
</li>
<li>
<p>上面创建不了的要先实名一下，这个实名通过挺快的。创建好后点击你的空间名称就可以进到<strong>图床控制面板</strong>中了</p>
</li>
<li>
<p>然后进入<strong>域名控制面板</strong>，像上面搭建个人博客的第4步一样创建一个新的<strong>解析</strong>，填写见下图：</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328162241348.png" alt="image-20240328162241348" /></p>
</li>
<li>
<p>创建好后来到<strong>图床控制面板</strong>，选择<strong>域名管理</strong>，点击<strong>绑定域名</strong>，如图：</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328162637030.png" alt="image-20240328162637030" /></p>
</li>
<li>
<p>填写内容及选项见下面图：</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328163004050.png" alt="image-20240328163004050" /></p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328163108484.png" alt="image-20240328163108484" /></p>
</li>
<li>
<p>其余地方都不用修改，编辑好后点击创建即可，创建好后点击右侧的<strong>所有权验证</strong></p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328163316734.png" alt="image-20240328163316734" /></p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328163448511.png" alt="image-20240328163448511" /></p>
</li>
<li>
<p>再像上面一样去<strong>域名控制面板</strong>添加一个新的解析，<strong>记录类型</strong>，<strong>主机记录</strong>和<strong>记录值</strong>直接复制过去就行，解析创建好后回去上图位置点击<strong>点击验证</strong>即可验证成功</p>
</li>
<li>
<p>验证成功后可以看到CNAME下面显示未配置，其右边有一个小链接图标，鼠标悬浮上去点击<strong>复制</strong>，将这个值填入到上面创建解析时说“随便填，之后要回来改”的那个<strong>记录值</strong>的地方，替换掉原来随便填的内容</p>
</li>
</ul>
</li>
<li>
<p>配置PicGo</p>
<ul>
<li>
<p>打开第一步下载的PicGo软件，点击<strong>图床设置</strong>——<strong>七牛云</strong>，填写见下图，AK和SK复制填写时要保证是可见的状态，不能是黑点的样子复制(AK和SK如果没有点下面新增就行)</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328165440585.png" alt="image-20240328165440585" /></p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328165826029.png" alt="image-20240328165826029" /></p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328170058378.png" alt="image-20240328170058378" /></p>
</li>
<li>
<p>到上面必填项都填完了，下面两项可以不填，其中的存储路径不填就是将图片保存在跟目录，如果填的话就相当于创建一个文件夹，下面举一个创建的例子，如下图：</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328172214093.png" alt="image-20240328172214093" /></p>
</li>
<li>
<p>在图床控制面板选择文件管理，点击<strong>创建目录</strong>，随意取名创建一个存储图片的文件夹，然后在PicGo的中存储路径中填入你取的文件夹的名称加“/”，如图：</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328172805165.png" alt="image-20240328172805165" /></p>
</li>
<li>
<p>这样就完成了PicGo 七牛云图床的配置，你也创建更多图床文件夹，以便把各类图片分开存储，下面让我们来试着上传图片检测一下。在PicGo的<strong>上传区</strong>上面可以选择要上传的位置，如图：</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328173224783.png" alt="image-20240328173224783" /></p>
</li>
<li>
<p>选择好后你就可以选择一张图片上传了，等待上传好后可以在<strong>相册</strong>中看到你上传的图片，同时，在图床控制面板的文件管理选项中你创建的文件夹里也可以看到你上传的图片。接着打开浏览器把图片的链接粘贴进去就可以看到你上传的图片了。点击如下图所示的图标可以复制该图的链接，在写博客的时候可以直接使用这个链接插入图片，这样别人也能看到你博客里的图片了</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328173756755.png" alt="image-20240328173756755" /></p>
</li>
</ul>
</li>
</ol>

<h2>三、Typora设置</h2>
<p>为了能把写好的Markdown文件上传到WordPress，以及在WordPress中使用Markdown进行写作，我们需要进行一下设置</p>
<ol>
<li>
<p>Typora设置</p>
<ul>
<li>
<p>在Typora的偏好设置里找到下图所示位置进行设置，找到你自己安装PicGo的位置，设置好后点击<strong>验证图片上传选项</strong>按钮进行测试，成功则配置完成</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328174448162.png" alt="image-20240328174448162" /></p>
</li>
</ul>
</li>
<li>
<p>安装WordPress插件</p>
<ul>
<li>
<p>在WordPress仪表盘的插件选项中添加名为<strong>WP Githuber MD</strong>的插件并启用，如下图：</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328175221288.png" alt="image-20240328175221288" /></p>
</li>
<li>
<p>这个插件可以把Markdown转为HTML，这样我们就可以把Markdown上传到WordPress了</p>
</li>
</ul>
</li>
<li>
<p>在Typora写完文章后点击菜单栏的<strong>格式</strong>——<strong>图像</strong>——<strong>上传所有本地图像</strong>，就可以把文章中所有的图像都上传到图床里，之后只要`<code>Ctrl+A</code>全选文章<code>Ctrl+C</code>复制<code>Ctrl+V</code>粘贴到WordPress新文章里就可以把本地Markdown发布到WordPress博客了</p>
<p><img src="https://tuchuang.shifengzhi.top/picture/image-20240328184013712.png" alt="image-20240328184013712" /></p>
<ul>
<li>在Typora修改文章又新上传图片后，选择<strong>上传所有本地图片</strong>时只会上传新添加的图片，不会重复上传已经上传过的图片</li>
</ul>
</li>
</ol>
